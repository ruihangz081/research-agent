# Table Rules

- Use GFM pipe tables with a single header row.
- Put text columns first and align numeric columns consistently.
- Include units in column headings rather than repeating them in every cell.
- Keep comparable periods and definitions in the same table; split tables when definitions or units diverge.
- Use `—` for unavailable values and label estimates with `E` or an explicit note.
- Put `资料来源：...` directly below the table and add an as-of date when it is not obvious.
- Prefer fewer than eight visible columns on portrait A4. Split wide tables instead of shrinking text below readable size.
- Keep SWOT, risk matrices, evidence matrices, and qualitative comparisons as tables; do not turn them into coordinate diagrams.
- Never place a chart placeholder inside a table.
