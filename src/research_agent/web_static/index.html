RESEARCH SURFACES

五个工作面，覆盖一条完整研究链路

从提出问题、组织材料，到跟踪智能体和交付成果，每一个环节都在同一个本地工作台里保持可见、可控、可复用。

⌂01
RESEARCH CONTROL

研究首页

从一个研究主题开始，集中掌握任务状态、审批节点与下一步动作。

  • 任务状态与进度总览
  • 检查点审批与继续运行

AGENT WORKSPACE

项目工作区

实时跟随 Agent 的执行轨迹，把轮次、日志、检查点和项目产物放在同一视野。

  • 轮次、日志与阶段时间线
  • 并排阅读项目产物
打开项目工作区 →

SOURCE LIBRARY

材料中心

统一接入、解析和检索研究材料，让分散的信息沉淀为可复用的资产库。

  • 解析、OCR 与元数据管理
  • 检索、版本比较与归档
管理研究材料 →

集中预览洞察、Markdown 草案和正式报告，把研究结果整理成可交付文件。

  • PDF、TeX 与交付文件导出

  • 本地路径和默认轮次配置
